A deterministic, standard-library-only Python program that draws a one-page newspaper summing up the world news of Sunday 22 November 2026: the COP31 climate talks in Antalya going into overtime with "fossil fuels" left out of the Sunday draft, tankers hit near Hormuz and missiles intercepted over Riyadh, France's sixth weekend of protests, record flooding on Florida's St. Johns River, toxic liquor deaths in Manipur, a magnitude 6.7 quake in Peru, and the day's sport. The image is drawn entirely by code (pixel canvas, built-in 5x7 bitmap font, hand-rolled PNG encoder), so every run produces byte-identical output with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && ls -l out/entry.png
```
